# Statistics

Exercises and labs working through core statistics, organised by day. Each notebook keeps its
outputs, so the work is visible without re-running.

| Day | Topic | Covers |
|-----|-------|--------|
| 1 | Probability distributions | discrete, constant and normal distributions |
| 2 | Hypothesis testing | hypothesis tests and t-tests |
| 3 | A/B testing | frequentist and Bayesian A/B tests |
| 4 | Linear regression | regression, plus a small modelling competition |

Python with `pandas`, `numpy`, `scipy` and `matplotlib`.
